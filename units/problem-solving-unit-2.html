🛠️ PROBLEM SOLVING TECHNIQUES · UNIT II

Structured programming

Structured programming uses three simple shapes: do steps in order, choose a path, or repeat a block. This unit shows how those shapes become safe conditions and loops in C.

PICTURE IT

A program can go straight ahead, choose a path, or repeat a step. That is sequence, selection and repetition.

A route can go straight, choose left or right at a sign, or repeat a lap until the timer rings. Programs use the same three patterns.

  • Recognize sequence, selection and repetition.
  • Choose if/else, switch, while or do-while for a task.

LESSON PATH

Build the idea step by step

Read one card, say it back in your own words, then try the example.

01

Sequence, selection and repetition

Sequence runs statements in order. Selection chooses a branch, commonly with if/else or switch. Repetition runs a block while a condition holds. Combining these structures produces programs that are easier to read and reason about.

02

Choose the loop that matches the task

A while loop tests before the body, so it may run zero times. A do-while loop tests after the body, so it runs at least once; it often suits a menu that must appear once. Every loop needs an initial state, a condition and an update that eventually makes the condition false.

03

Sentinels stop input safely

A sentinel is a special value marking the end of input and is not part of the data. Choose one that cannot be confused with valid input, or use a separate end marker. Translate pseudocode into C in small pieces, then test zero, one and boundary values for off-by-one mistakes.

✦

WORK IT THROUGH

Display odd numbers from 1 through n.

  1. Set i=1. While i<=n, display i and add 2 to i.
  2. For n=6, the loop shows 1, 3 and 5. The next value is 7, so the condition is false.
  3. For n<1, the condition is false at the start and nothing is displayed; that is correct for this rule.

WATCH OUT FOR

Easy mix-ups

  • A while loop might run zero times; a do-while loop runs at least once.
  • If a loop variable never moves toward the stopping condition, it may never end.
  • Do not include a sentinel in a total or average.

IMPORTANT QUESTIONS · TAP TO REVEAL MODEL ANSWERS
QUESTION 1Compare while and do-while loops.+

A while loop is entry-controlled: its condition is tested before each pass, so its body may run zero times. A do-while loop is exit-controlled: the body runs once before the condition is tested, so it runs at least once. Use while when the loop may not need to start, such as reading until an input is available. Use do-while for a menu that must be shown at least once.

QUESTION 2Write the logic for displaying odd numbers from 1 through n.+

Initialize i to 1. While i is less than or equal to n, display i and add 2 to i. The loop visits 1, 3, 5 and so on, so every displayed value is odd and no value exceeds n. If n is less than 1, the loop displays nothing. In C, the loop condition is i <= n and the update is i += 2.
