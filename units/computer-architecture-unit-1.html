Digital logic & number systems

A computer turns information into patterns of 0s and 1s. This unit teaches how those patterns represent numbers and characters, how logic rules describe decisions, and how a K-map can simplify a circuit before it is built.

PICTURE IT

Computers use tiny yes/no switches. We call their two answers 1 and 0.

Imagine a wall of tiny light switches. Each switch is either off (0) or on (1). A row of switches can store a number, a letter, or instructions.

BY THE END, YOU CAN

  • Convert binary, octal and hexadecimal numbers using place values or bit groups.
  • Use Boolean ideas and Karnaugh maps to simplify a logic function.
  • Explain basic coding, parity and the stored-program computer.

LESSON PATH

Build the idea step by step

Read one card, say it back in your own words, then try the example.

01

Numbers are built from place values

In base 10, the places are powers of 10. Binary uses powers of 2: the rightmost bit is 1, then 2, 4, 8, and so on. A 1 means include this place; a 0 means leave it out. To change binary to decimal, add the included place values. To convert binary to octal, group bits in threes; for hexadecimal, group in fours, padding with zeroes if needed.

02

Logic rules describe switch decisions

Boolean variables have two values, 0 and 1. AND is 1 only when both inputs are 1; OR is 1 when at least one input is 1; NOT flips a value. A truth table lists every input and output. A Karnaugh map arranges outputs so neighboring cells differ in one variable. Groups of 1s (sum of products) or 0s (product of sums) remove variables that change.

03

Codes and computer organization give bits meaning

Gray code changes one bit between neighboring values. ASCII and EBCDIC assign bit patterns to characters. A parity bit can detect an odd number of flipped bits, but it cannot identify or correct the wrong bit. In the Von Neumann model, instructions and data share memory and the processor fetches instructions from it.

WORK IT THROUGH

Convert 101101.01₂ to decimal.

  1. Read each digit with its binary place: 32 + 8 + 4 + 1 = 45.
  2. After the binary point, the places are 1/2 and 1/4. The digits add 0 + 1/4, so the fraction is 0.25.
  3. The answer is 45.25₁₀. For hexadecimal, group as 0010 1101 . 0100, which gives 2D.4₁₆.

WATCH OUT FOR

Easy mix-ups

  • Do not read binary places as powers of 10.
  • K-map edge cells can be adjacent; diagonal cells are not.
  • Parity can detect some errors, but it is not a correction method.

CORE IDEAS TO REMEMBER
01

A digital signal represents a finite set of levels; binary logic uses 0 and 1.

02

Von Neumann architecture stores instructions and data in memory and uses a processor to fetch and execute instructions.

03

K-map groups adjacent 1-cells for SOP or 0-cells for POS. Group sizes are powers of two.

04

Binary, octal and hexadecimal conversions use positional weights; group binary digits by 3 for octal and 4 for hexadecimal.

05

Gray code changes one bit between adjacent values; ASCII and EBCDIC encode characters; parity can detect some errors.

IMPORTANT QUESTIONS · TAP TO REVEAL MODEL ANSWERS
QUESTION 1Simplify F(A,B,C)=sum m(1,3,5,7) using a K-map.+

Place 1s in minterms 1, 3, 5 and 7. These are all combinations where C=1, regardless of A and B. Group the four adjacent cells as one group. A and B vary within the group and cancel; C remains. Therefore F=C. In a full exam answer, draw the correctly labelled K-map, show the group and state the simplified result.

QUESTION 2Convert (101101.01)2 to decimal.+

Use positional weights. The integer part is 1x32 + 0x16 + 1x8 + 1x4 + 0x2 + 1x1 = 45. The fractional part is 0x1/2 + 1x1/4 = 0.25. Therefore (101101.01)2 = 45.25 in decimal. For hexadecimal, group as 0010 1101 . 0100, giving 2D.4 in base 16.
