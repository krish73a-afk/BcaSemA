Digital logic & number systems

A computer turns information into patterns of 0s and 1s. This unit teaches how those patterns represent numbers and characters, how logic rules describe decisions, and how a K-map can simplify a circuit before it is built.

PICTURE IT

Computers use tiny yes/no switches. We call their two answers 1 and 0.

Imagine a wall of tiny light switches. Each switch is either off (0) or on (1). A row of switches can store a number, a letter, or instructions.

01

Digital signals and binary logic

A digital system represents information with a small set of distinct levels. Binary uses two logical values: 0 and 1. A bit is one binary digit, and groups of bits can represent numbers, characters or control information. Boolean algebra describes combinations of these values: AND, OR and NOT are the basic operations. A truth table lists the output for every possible input combination.

Simple example

For A=1 and B=0, A AND B is 0, A OR B is 1, and NOT B is 1.

Exam takeawayDefine the 0/1 levels, name the operation, and show its truth table or expression.
02

Stored-program (Von Neumann) organization

The Von Neumann model stores program instructions and data in the same main memory. A processor fetches an instruction, interprets it and performs its operation. The same stored-program idea lets a general-purpose computer run different programs without rewiring its circuits. In the basic model, instructions and data share communication paths, which can limit throughput.

Simple example

A program instruction and the value it adds can both be stored as bit patterns in memory.

Exam takeawayState where instructions and data are held, then describe the fetch-and-execute role of the CPU.
03

Number systems and conversion

A positional number system assigns each digit a weight based on its place and base. Binary uses powers of 2, octal powers of 8, decimal powers of 10 and hexadecimal powers of 16. Convert to decimal by summing digit × place value. Binary-to-octal conversion groups bits in threes; binary-to-hexadecimal groups them in fours, padding the outside group with zeroes when necessary.

Simple example

101101₂ = 1×32 + 0×16 + 1×8 + 1×4 + 0×2 + 1×1 = 45₁₀.

Exam takeawayWrite the place values or show bit groups; include the base on every number.
04

Karnaugh maps and Boolean simplification

A Karnaugh map is a visual form of a truth table arranged in Gray-code order, so adjacent cells differ in one variable. For sum of products, place 1s and group adjacent 1-cells; for product of sums, group 0-cells. Group sizes must be powers of two. Make groups as large as possible, and remember that opposite edges wrap around as neighbors. A variable that changes within a group disappears from the simplified term.

Simple example

For F(A,B,C)=Σm(1,3,5,7), all marked cells have C=1, so the four-cell group simplifies to F=C.

Exam takeawayLabel the map, place values, circle legal groups, then show which variables remain.
05

Gray code, character codes and parity

Gray code orders values so adjacent codes differ by only one bit, reducing ambiguity while a value changes. Character codes assign binary patterns to letters and symbols; the guide names ASCII and EBCDIC. A parity bit is added so the total number of 1s is even or odd. A parity mismatch can detect some transmission errors, especially an odd number of flipped bits, but parity cannot locate or repair the error.

Simple example

If a data word has an even number of 1s, even parity adds 0; odd parity adds 1.

Exam takeawayExplain what the code represents and state the limitation of parity detection.
06

Boolean operators and truth tables

Boolean algebra treats each input as either 0 or 1. AND produces 1 only when every input is 1; OR produces 1 when at least one input is 1; NOT reverses a bit. XOR produces 1 when its two inputs differ. A truth table is the safest way to verify a rule because it checks every possible input row before the circuit is built.

Simple example

For A=1 and B=0, A XOR B=1; for A=1 and B=1, A XOR B=0.

Exam takeawayWrite the operator rule, then include every input combination and its output.
07

Sum of products and product of sums

A sum-of-products expression ORs together AND terms, such as AB + A'C. A product-of-sums expression ANDs together OR terms, such as (A+B)(A'+C). To build SOP from a truth table, write one minterm for each output-1 row. To build POS, write a maxterm for each output-0 row. K-maps then simplify the expression without changing its truth table.

Simple example

If output is 1 only for A=1,B=0, the minterm is AB'.

Exam takeawayState whether you are grouping 1s for SOP or 0s for POS before simplifying.
08

Signed binary and two's complement

Unsigned n-bit values range from 0 to 2ⁿ−1. Two's-complement signed values use the leftmost bit as a negative place weight, giving a range from −2ⁿ⁻¹ to 2ⁿ⁻¹−1. To form a negative value, invert all bits of its positive form and add 1. The same binary adder can then add signed values; overflow occurs when the mathematical result is outside the representable range.

Simple example

In 8 bits, +5=00000101. Invert to 11111010 and add 1: −5=11111011.

Exam takeawayState the bit width, show invert-plus-one, and check the signed range for overflow.
09

Binary fractions and fixed place values

Digits to the right of the binary point have weights 1/2, 1/4, 1/8 and so on. Add the weights whose bits are 1. Some decimal fractions repeat forever in binary, so a computer with a fixed number of fraction bits stores an approximation. This explains why a displayed decimal result may differ by a tiny rounding amount.

Simple example

0.101₂ = 1/2 + 0/4 + 1/8 = 0.625₁₀.

Exam takeawayWrite the fractional weights explicitly and mention rounding when a value cannot be represented exactly.

How the unit fits together

Connect the definitions, methods and applications before you start memorizing.

Digital logic starts by making a complicated real-world question finite. Decide which inputs matter, name them with variables, and describe the required output. A truth table then lists every input combination. Boolean algebra and a Karnaugh map are two ways of simplifying the same rule: algebra manipulates expressions, while the map makes patterns visible. The map uses Gray-code ordering so adjacent cells differ by one variable. When a group is formed, any variable that changes inside it is irrelevant to that group and disappears. Number systems use a related idea of structure: a bit's position gives it a weight, so the same 1 can mean 1, 2, 4, 8 and more. Character codes and error bits add conventions that let stored bits represent text and check a transmission.

Quick recap: teach these links back

01

Numbers are built from place values

In base 10, the places are powers of 10. Binary uses powers of 2: the rightmost bit is 1, then 2, 4, 8, and so on. A 1 means include this place; a 0 means leave it out. To change binary to decimal, add the included place values. To convert binary to octal, group bits in threes; for hexadecimal, group in fours, padding with zeroes if needed.

02

Logic rules describe switch decisions

Boolean variables have two values, 0 and 1. AND is 1 only when both inputs are 1; OR is 1 when at least one input is 1; NOT flips a value. A truth table lists every input and output. A Karnaugh map arranges outputs so neighboring cells differ in one variable. Groups of 1s (sum of products) or 0s (product of sums) remove variables that change.

03

Codes and computer organization give bits meaning

Gray code changes one bit between neighboring values. ASCII and EBCDIC assign bit patterns to characters. A parity bit can detect an odd number of flipped bits, but it cannot identify or correct the wrong bit. In the Von Neumann model, instructions and data share memory and the processor fetches instructions from it.

Follow every step

Try each task yourself first, then compare your working with the explanation.

EXAMPLE 1

Convert a binary fraction and check it in hexadecimal

TaskConvert 101101.01₂ to decimal and hexadecimal.

  1. For the integer part, write powers of 2 from right to left: 1, 2, 4, 8, 16, 32.
  2. Add the places containing 1: 32+8+4+1=45. For the fraction, the first place is 1/2 and the second is 1/4; only the second bit is 1, so the fraction is 0.25.
  3. For hexadecimal, group from the binary point: 0010 1101 . 0100. The groups map to 2, D and 4.
Answer and reason

101101.01₂ = 45.25₁₀ = 2D.4₁₆. The zero padding changes no value.

EXAMPLE 2

Simplify a function with a K-map

TaskSimplify F(A,B,C)=Σm(1,3,5,7).

  1. Write each minterm as an ABC binary row: 001, 011, 101 and 111.
  2. Place 1 in those four K-map cells. They form one legal group of four; edge adjacency is allowed when the map wraps.
  3. Across the group, A changes and B changes, but C stays 1. Remove the changing variables.
Answer and reason

F=C. In an exam, draw and label the map, show the group and state which variable remains.

QUESTION 1Simplify F(A,B,C)=sum m(1,3,5,7) using a K-map.+

Place 1s in minterms 1, 3, 5 and 7. These are all combinations where C=1, regardless of A and B. Group the four adjacent cells as one group. A and B vary within the group and cancel; C remains. Therefore F=C. In a full exam answer, draw the correctly labelled K-map, show the group and state the simplified result.

QUESTION 2Convert (101101.01)2 to decimal.+

Use positional weights. The integer part is 1x32 + 0x16 + 1x8 + 1x4 + 0x2 + 1x1 = 45. The fractional part is 0x1/2 + 1x1/4 = 0.25. Therefore (101101.01)2 = 45.25 in decimal. For hexadecimal, group as 0010 1101 . 0100, giving 2D.4 in base 16.

WORK IT THROUGH

Convert 101101.01₂ to decimal.

  1. Read each digit with its binary place: 32 + 8 + 4 + 1 = 45.
  2. After the binary point, the places are 1/2 and 1/4. The digits add 0 + 1/4, so the fraction is 0.25.
  3. The answer is 45.25₁₀. For hexadecimal, group as 0010 1101 . 0100, which gives 2D.4₁₆.
