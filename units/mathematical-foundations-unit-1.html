Sets, relations & functions

Sets collect objects, relations connect them, and functions assign outputs. This unit builds a dependable method for checking relation properties and understanding how functions and relationships behave.

LESSON PATH

Build the idea step by step

Read one card, say it back in your own words, then try the example.

01

Sets and ordered pairs describe collections and links

A set is a collection of distinct elements. Union gathers elements from either set, intersection keeps shared elements, and difference keeps elements in the first but not the second. The Cartesian product A×B contains ordered pairs (a,b); order matters. A relation from A to B is any subset of A×B.

02

Test relation properties one at a time

On a set A, reflexive means every a is related to itself; symmetric means aRb implies bRa; transitive means aRb and bRc imply aRc. An equivalence relation has all three. Its equivalence classes group elements that are equivalent, and those classes partition the set into non-overlapping groups.

03

Functions and reachability are structured rules

A function gives each input exactly one output. Injective means different inputs have different outputs; surjective means every codomain value is reached; bijective means both. Warshall's algorithm starts from an adjacency matrix and considers each vertex k as a possible intermediate point. It adds reachability from i to j when i reaches k and k reaches j.

✦

WORK IT THROUGH

Check a R b when a−b is divisible by 3.

  1. Reflexive: a−a=0, divisible by 3, so aRa.
  2. Symmetric: if a−b is divisible by 3, then b−a is its negative and is also divisible by 3.
  3. Transitive: if a−b and b−c are divisible by 3, their sum a−c is divisible by 3. The classes are numbers with the same remainder mod 3.

WATCH OUT FOR

Easy mix-ups

  • Check each relation property separately; one does not prove another.
  • A function may map several inputs to one output and still be a function.
  • Clarify whether reachability includes a zero-length path from a vertex to itself.

CORE IDEAS TO REMEMBER
01

For sets A and B, A x B contains ordered pairs (a,b). The order matters.

02

A relation R on A is a subset of A x A. Check reflexive, symmetric and transitive properties separately.

03

An equivalence relation is reflexive, symmetric and transitive; its equivalence classes partition the set.

04

A function is injective if distinct inputs have distinct outputs, surjective if every codomain value is reached, and bijective if both.

05

Warshall's algorithm builds reachability: for each intermediate k, set M[i,j] to 1 when M[i,k] and M[k,j] are both 1.

IMPORTANT QUESTIONS · TAP TO REVEAL MODEL ANSWERS
QUESTION 1What makes a relation an equivalence relation? Give an example.+

A relation must be reflexive, symmetric and transitive. On the integers, define a R b when a-b is divisible by 3. Every integer is related to itself; if a-b is divisible by 3, so is b-a; and if a-b and b-c are divisible by 3, then a-c is divisible by 3. The classes are numbers with the same remainder on division by 3: {0,3,6,...}, {1,4,7,...}, and {2,5,8,...}, extending to negative integers.

QUESTION 2Explain Warshall's algorithm and what it produces.+

Start with the adjacency matrix of a directed graph. For each vertex k, treat k as a possible intermediate point. For every pair i,j, update M[i,j] = M[i,j] OR (M[i,k] AND M[k,j]). After all k values, M[i,j] is 1 exactly when a path from i to j exists. State whether the diagonal starts with zeros or ones according to whether the question asks for positive-length paths or reflexive reachability.
