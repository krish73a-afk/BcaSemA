01

Sets and set operations

A set is a well-defined collection of distinct objects called elements. The union A∪B contains elements in A or B; the intersection A∩B contains elements in both; and A−B contains elements in A but not B. The complement depends on a stated universal set. Venn diagrams can show these relationships, but define the sets and universe before interpreting a shaded region.

Simple example

If A={1,2,3} and B={3,4}, then A∩B={3} and A∪B={1,2,3,4}.

Exam takeawayState membership carefully and use braces for set elements.
02

Cartesian products and ordered pairs

The Cartesian product A×B contains every ordered pair (a,b) with a in A and b in B. Order matters: (a,b) is generally different from (b,a). If A has m elements and B has n, then A×B has mn ordered pairs. A relation from A to B is any subset of this product.

Simple example

For A={1,2} and B={x,y}, A×B={(1,x),(1,y),(2,x),(2,y)}.

Exam takeawayList pairs in the correct order and count them with |A×B|=|A||B|.
03

Relations and their properties

A relation R on A is a set of ordered pairs from A×A. Reflexive means every element is related to itself. Symmetric means aRb implies bRa. Transitive means aRb and bRc together imply aRc. Test each property using its definition; a counterexample is enough to show that a property fails.

Simple example

“Is a sibling of” is usually symmetric, but it is not reflexive because a person is not their own sibling.

Exam takeawayCheck reflexive, symmetric and transitive one by one.
04

Equivalence relations and classes

An equivalence relation is reflexive, symmetric and transitive. It groups elements that count as equivalent under a chosen rule. The equivalence class of a contains every element related to a; classes partition the set, so each element belongs to one class and distinct classes do not overlap. Congruence modulo n groups integers by their remainder after division by n.

Simple example

For aRb when 3 divides a−b, integers are grouped into remainder classes 0, 1 and 2 modulo 3.

Exam takeawayProve the three properties, then identify the resulting classes.
05

Functions: injective, surjective and bijective

A function assigns each domain input exactly one output in the codomain. It may send different inputs to the same output. It is injective (one-to-one) if different inputs always have different outputs; surjective (onto) if every codomain value is reached; bijective if both. Check the stated domain and codomain before classifying a function.

Simple example

f(x)=x² from real numbers to real numbers is not injective because f(2)=f(−2), and it is not onto because negative outputs are missing.

Exam takeawayUse the definitions and state the domain/codomain.
06

Warshall's transitive-closure algorithm

Warshall's algorithm finds reachability in a directed graph. Start with an adjacency matrix M. For each possible intermediate vertex k, update each entry: M[i,j] = M[i,j] OR (M[i,k] AND M[k,j]). A 1 then means i can reach j using the allowed intermediate vertices. Decide whether the diagonal should include zero-length self-reachability, as the question specifies.

Simple example

If edge 1→2 and edge 2→3 exist, considering k=2 adds reachability 1→3.

Exam takeawayShow the matrix after each k and state how self-reachability is treated.
07

Set identities and complements

Set operations follow useful identities: union and intersection are commutative and associative, while distributive laws connect them. De Morgan's laws say the complement of a union is the intersection of the complements, and vice versa. A Venn diagram makes these relationships visible; an element-by-element argument can prove them precisely.

Simple example

If x is not in A∪B, then x is in neither A nor B, so x is in A'∩B'.

Exam takeawayState the universe and use either a Venn diagram or an element argument.
08

Counting Cartesian-product pairs

The Cartesian product A×B contains all ordered pairs whose first element comes from A and second from B. Because the order matters, (a,b) and (b,a) are generally different. If A has m elements and B has n, the product has mn pairs. A small grid prevents missing or repeating pairs.

Simple example

A={1,2}, B={x,y}: A×B={(1,x),(1,y),(2,x),(2,y)}.

Exam takeawayList pairs in a consistent order and check the count with |A×B|=|A||B|.
09

Relation matrices and digraphs

A relation on a finite set can be shown as ordered pairs, a Boolean matrix or a directed graph. In its matrix, entry (i,j) is 1 when the relation includes (i,j). A directed edge i→j represents the same fact. Choose the representation that makes the property you need to test easiest to see.

Simple example

For R={(1,1),(1,2),(2,2)}, draw loops at 1 and 2 and an arrow 1→2.

Exam takeawayState the element order used for rows and columns so the matrix is unambiguous.
10

Function mappings and inverse functions

A mapping diagram shows whether each domain element has exactly one arrow to the codomain. A function has an inverse function only when it is one-to-one and onto on the stated domain and codomain. To find an inverse, write y=f(x), solve for x, then exchange the variable names and check the domain restrictions.

Simple example

For f(x)=2x+3 on the reals, y=2x+3 gives x=(y−3)/2, so f⁻¹(x)=(x−3)/2.

Exam takeawayState the domain and codomain before claiming an inverse exists.
11

Set difference and symmetric difference

A−B contains elements that are in A but not in B. The symmetric difference A△B contains elements that belong to exactly one of the sets. These operations are useful for comparing groups and checking membership. A Venn diagram makes clear which regions are shaded; remember that A−B is not generally the same as B−A.

Simple example

A={1,2,3}, B={3,4}: A−B={1,2}; A△B={1,2,4}.

Exam takeawayWrite the universe and shade or list the correct regions.
12

Reflexive, symmetric and transitive tests

Test each property independently. Reflexive requires every (a,a); symmetric requires the reverse pair whenever (a,b) is present; transitive requires (a,c) whenever (a,b) and (b,c) are present. One counterexample disproves a property. For a finite relation, a matrix or arrow diagram can expose missing pairs quickly.

Simple example

R={(1,1),(1,2),(2,1),(2,2)} on {1,2} is reflexive, symmetric and transitive.

Exam takeawayUse the definition for each property and show a counterexample if it fails.
13

Equivalence classes as partitions

If a relation is an equivalence relation, each element's class contains all elements equivalent to it. Classes cover the set and do not overlap unless they are identical, so they form a partition. To find classes, choose a representative and test which elements satisfy the relation; then check that no element is omitted.

Simple example

Congruence modulo 3 partitions integers into remainders 0, 1 and 2.

Exam takeawayList a representative, its class and explain why the classes partition the set.
14

Warshall updates with an adjacency matrix

Warshall's algorithm tests one intermediate vertex at a time. At stage k, M[i,j] becomes 1 if it was already 1 or if i reaches k and k reaches j. The Boolean AND checks a two-part path; OR keeps any known path. Keep a separate matrix after each k for small examples to avoid mixing updates.

Simple example

If at k=2, M[1,2]=1 and M[2,3]=1, update M[1,3] to 1.

Exam takeawayShow the initial matrix, each intermediate-vertex step and the final reachability meaning.
15

Set notation and membership

A set is a well-defined collection. The symbol ∈ means an object belongs to a set, while ⊆ means every element of one set is in another. Order and repetition do not change a set: {1,2,2}={2,1}. Use braces for the set and name the universe so complements are unambiguous.

Simple example

If A={1,3,5}, then 3∈A, 2∉A and {1,3}⊆A.

Exam takeawayState the universe, use membership symbols correctly and remove duplicate elements.
16

Set operations and Venn diagrams

Union A∪B contains elements in either set; intersection A∩B contains elements common to both; difference A−B keeps elements of A not in B. A complement contains universe elements outside A. A Venn diagram makes overlap visible, but labels and region shading must match the requested operation.

Simple example

A={a,b,c}, B={b,c,d}: A∪B={a,b,c,d}, A∩B={b,c}, A−B={a}.

Exam takeawayWrite the membership rule first, then shade or list exactly those elements.
17

Cartesian products and ordered pairs

The Cartesian product A×B contains every ordered pair (a,b) with a∈A and b∈B. The first coordinate comes from A and the second from B, so switching the sets can change the product. If A and B are finite, |A×B|=|A||B|. Ordered pairs are equal only when both coordinates match.

Simple example

{1,2}×{x,y}={(1,x),(1,y),(2,x),(2,y)} has 2×2=4 pairs.

Exam takeawayKeep the coordinate order fixed and count the product before listing it.
18

Representing relations with matrices and digraphs

A relation on a finite set can be shown as ordered pairs, a 0–1 matrix or a directed graph. In the matrix, row i and column j contains 1 exactly when the relation links i to j. In the digraph, vertices are elements and arrows show related pairs. These views help inspect reflexivity, symmetry and paths.

Simple example

For R={(1,1),(1,2),(2,2)}, matrix rows are 1 1 / 0 1 and the graph has loops at 1 and 2 plus arrow 1→2.

Exam takeawayDeclare the element order before drawing a relation matrix or graph.
19

Equivalence classes and partitions

An equivalence relation is reflexive, symmetric and transitive. It groups a set into disjoint equivalence classes: every element belongs to one class, and classes either match or do not overlap. Congruence modulo n is a common example because numbers are grouped by remainder. This turns a large set into useful categories.

Simple example

Modulo 3, integers split into [0]={…,−3,0,3,…}, [1] and [2].

Exam takeawayProve all three relation properties, then show the resulting classes cover the set without overlap.
20

Function composition and inverse

Composition f∘g applies g first and then f, so the output of g must belong to the domain of f. An inverse reverses inputs and outputs; it is a function only when the original mapping is one-to-one and onto the chosen codomain. Check domain and codomain instead of manipulating a formula alone.

Simple example

f(x)=2x+1 has inverse f⁻¹(y)=(y−1)/2 over real numbers; applying one after the other returns the starting value.

Exam takeawayWrite the order of composition and verify an inverse using f(f⁻¹(x))=x.

How the unit fits together

Connect the definitions, methods and applications before you start memorizing.

Discrete mathematics is precise because every object has a defined membership rule. A relation is a set of ordered pairs; its properties describe patterns in those links. Equivalence relations are useful because they divide a set into classes without overlap. Functions add a stricter rule: each input must have exactly one output, while injective and surjective describe how inputs and outputs correspond. Graph reachability is the same kind of relation question expressed as paths. Warshall's algorithm updates a Boolean matrix so each stage permits one more intermediate vertex. Track the meaning of a matrix entry throughout the calculation: 1 means a path is known to exist, not that a numeric quantity has been added.

Quick recap: teach these links back

01

Sets and ordered pairs describe collections and links

A set is a collection of distinct elements. Union gathers elements from either set, intersection keeps shared elements, and difference keeps elements in the first but not the second. The Cartesian product A×B contains ordered pairs (a,b); order matters. A relation from A to B is any subset of A×B.

02

Test relation properties one at a time

On a set A, reflexive means every a is related to itself; symmetric means aRb implies bRa; transitive means aRb and bRc imply aRc. An equivalence relation has all three. Its equivalence classes group elements that are equivalent, and those classes partition the set into non-overlapping groups.

03

Functions and reachability are structured rules

A function gives each input exactly one output. Injective means different inputs have different outputs; surjective means every codomain value is reached; bijective means both. Warshall's algorithm starts from an adjacency matrix and considers each vertex k as a possible intermediate point. It adds reachability from i to j when i reaches k and k reaches j.

EXAMPLE 1

Test congruence modulo 3

TaskLet aRb when 3 divides a−b. Show that R is an equivalence relation.

  1. Reflexive: a−a=0, and 3 divides 0.
  2. Symmetric: if 3 divides a−b, then it divides −(a−b)=b−a.
  3. Transitive: if 3 divides a−b and b−c, it divides their sum a−c.
  4. Therefore all three properties hold; classes group integers with the same remainder mod 3.
Answer and reason

The classes are remainder 0, remainder 1 and remainder 2 modulo 3.

EXAMPLE 2

Run one Warshall update

TaskEdges are 1→2 and 2→3. What reachability is added when vertex 2 is allowed as an intermediate?

  1. Initially M[1,2]=1 and M[2,3]=1.
  2. For i=1,j=3,k=2, compute M[1,3] OR (M[1,2] AND M[2,3]).
  3. That is 0 OR (1 AND 1)=1.
  4. So the matrix records a path from 1 to 3 through 2.
Answer and reason

Warshall's update adds 1→3; keep the Boolean OR/AND meaning clear.

QUESTION 1What makes a relation an equivalence relation? Give an example.+

A relation must be reflexive, symmetric and transitive. On the integers, define a R b when a-b is divisible by 3. Every integer is related to itself; if a-b is divisible by 3, so is b-a; and if a-b and b-c are divisible by 3, then a-c is divisible by 3. The classes are numbers with the same remainder on division by 3: {0,3,6,...}, {1,4,7,...}, and {2,5,8,...}, extending to negative integers.

QUESTION 2Explain Warshall's algorithm and what it produces.+

Start with the adjacency matrix of a directed graph. For each vertex k, treat k as a possible intermediate point. For every pair i,j, update M[i,j] = M[i,j] OR (M[i,k] AND M[k,j]). After all k values, M[i,j] is 1 exactly when a path from i to j exists. State whether the diagonal starts with zeros or ones according to whether the question asks for positive-length paths or reflexive reachability.

WORK IT THROUGH

Check a R b when a−b is divisible by 3.

  1. Reflexive: a−a=0, divisible by 3, so aRa.
  2. Symmetric: if a−b is divisible by 3, then b−a is its negative and is also divisible by 3.
  3. Transitive: if a−b and b−c are divisible by 3, their sum a−c is divisible by 3. The classes are numbers with the same remainder mod 3.

CCSU BCA Semester I | Exam Notes Syllabus-led preparation | Verified coverage notes included   3  Unit I | Sets, relations and functions  Sets describe collections; relations describe links between elements; functions assign exactly one output to each input. The unit moves from set operations to relation properties, closures and function types.  Core ideas to remember  -   For sets A and B, A x B contains ordered pairs (a,b). The order matters.  -   A relation R on A is a subset of A x A. Check reflexive, symmetric and transitive properties separately.  -   An equivalence relation is reflexive, symmetric and transitive; its equivalence classes partition the set.  -   A function is injective if distinct inputs have distinct outputs, surjective if every codomain value is reached, and bijective if both.  -   Warshall's algorithm builds reachability: for each intermediate k, set M[i,j] to 1 when M[i,k] and M[k,j] are both 1.  Important questions with model answers  Question: What makes a relation an equivalence relation? Give an example.  Model answer  A relation must be reflexive, symmetric and transitive. On the integers, define a R b when a-b is divisible by 3. Every integer is related to itself; if a-b is divisible by 3, so is b-a; and if a-b and b-c are divisible by 3, then a-c is divisible by 3. The classes are numbers with the same remainder on division by 3: {0,3,6,...}, {1,4,7,...}, and {2,5,8,...}, extending to negative integers.  Question: Explain Warshall's algorithm and what it produces.  Model answer  Start with the adjacency matrix of a directed graph. For each vertex k, treat k as a possible intermediate point. For every pair i,j, update M[i,j] = M[i,j] OR (M[i,k] AND M[k,j]). After all k values, M[i,j] is 1 exactly when a path from i to j exists. State whether the diagonal starts with zeros or ones according to whether the question asks for positive-length paths or reflexive reachability.
