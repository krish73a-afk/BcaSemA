🧩 COMPUTER ARCHITECTURE · UNIT II

Circuits & memory bits

This unit moves from logic that only reacts to current inputs to circuits that can remember. That difference explains how computers add numbers, choose data, store bits and keep track of steps.

UNIT II20 individual concepts5-question mock

LEARN✦

PICTURE IT

A logic circuit is a set of little yes/no questions. Some circuits also remember what happened before.

A combinational circuit is like a calculator that answers from the buttons pressed now. A sequential circuit is like a notebook: its answer can depend on what was written earlier.

BY THE END, YOU CAN

  • Distinguish combinational logic from sequential logic.
  • Explain adders, multiplexers and decoders by their inputs and outputs.
  • Describe flip-flops, registers and counters as memory-building blocks.

01

Combinational and sequential circuits

A combinational circuit has no memory: its output is determined only by its current inputs. Adders, multiplexers and decoders are examples. A sequential circuit has stored state, so its output can depend on present inputs and what was stored earlier. Flip-flops and counters are sequential circuits. To classify a circuit, ask whether two identical current inputs can produce different outputs because the circuit remembers different past states.

Simple example

A decoder responds to its input code now; a counter remembers its current count before advancing.

Exam takeawayDefine the dependency and give one correct example of each type.
02

Half adders and full adders

A half adder adds two one-bit values. Its sum is A XOR B and its carry is A AND B. It has no carry-in, so it cannot by itself add the carry from a previous bit position. A full adder takes A, B and carry-in, then produces sum and carry-out. Full adders can be connected in sequence to add multi-bit binary numbers.

Simple example

1+1 gives sum 0 and carry 1, so the two-bit result is 10₂.

Exam takeawayCompare number of inputs, carry-in, outputs and where each adder is useful.
03

Multiplexers and decoders

A multiplexer (MUX) is a controlled selector: select lines choose one of several data inputs and route it to one output. With n select bits, it can choose among up to 2ⁿ inputs. A decoder takes an input code and activates the output line represented by that code. Both route information, but one chooses an input while the other identifies an output.

Simple example

A 4-to-1 MUX uses two select bits to choose one of four data inputs.

Exam takeawayDraw or describe inputs, select/code lines and output; do not swap their jobs.
04

Flip-flops store one bit

A flip-flop is a clocked storage element that holds one bit of state. The clock determines when an input can change the stored value. A D flip-flop copies D at its active clock event; an SR flip-flop has set and reset controls; JK and T flip-flops support other state changes, including toggle behavior. State the input rule and clock behavior when explaining a type.

Simple example

A D flip-flop with D=1 stores 1 at the active clock edge and keeps it until a later update.

Exam takeawayName its stored bit, input behavior and triggering clock event.
05

Registers and shift registers

A register is a group of flip-flops that stores a multi-bit value. A 4-bit register can hold one of 16 binary patterns. A shift register moves stored bits one place left or right on clock events; depending on its design, bits can enter or leave serially or in parallel. Registers are used for temporary CPU values, data movement and control.

Simple example

Shifting 1011 right by one position with a 0 entering on the left gives 0101.

Exam takeawayState the width, direction of movement, input style and clock action.
06

Counters and clocking

A counter is a sequential circuit that moves through a set of states in a regular order, often binary 000, 001, 010 and so on. A synchronous counter gives all flip-flops a shared clock, so state changes are coordinated. An asynchronous or ripple counter lets one stage trigger the next; propagation delay can accumulate through the stages. The unit guide expects this timing distinction.

Simple example

A 3-bit binary counter has eight states, from 000 through 111, before returning to 000.

Exam takeawayCompare clock connections and mention the ripple counter's accumulated delay.
07

Combinational versus sequential circuits

A combinational circuit has no memory: its output is determined by the inputs present now. A sequential circuit stores a state, so its output can depend on earlier inputs as well as current ones. A clock often coordinates state updates. When a question asks you to classify a circuit, look for a feedback path or a storage element such as a latch or flip-flop.

Simple example

An adder is combinational; a counter is sequential because it remembers its current count.

Exam takeawayExplain whether earlier input history can affect the present output.
08

Universal NAND and NOR gates

NAND and NOR are called universal because either gate type can be connected to implement NOT, AND and OR, and therefore any Boolean function. For example, feeding both inputs of a NAND from A gives NOT A. Universal-gate designs are useful when a circuit is built from one standard gate family, though the number of gates and delay still matter.

Simple example

A NAND inverter is Y=A NAND A=A'.

Exam takeawayShow the repeated-input inverter, then derive one other basic gate.
09

Flip-flop behavior and state tables

A flip-flop stores one bit and changes it at a clock event. A D flip-flop copies D to Q at the active edge. A T flip-flop holds when T=0 and toggles when T=1. A JK flip-flop holds, resets, sets or toggles according to J and K; the SR form has set and reset inputs, with a forbidden or undefined combination in the basic implementation. Use a state table to show present state and next state.

Simple example

For a T flip-flop with Q=0 and T=1 at the active edge, the next Q is 1.

Exam takeawayName the active clock event and distinguish present state from next state.
10

Synchronous counters and ripple counters

A counter moves through a sequence of binary states. In a synchronous counter, all flip-flops share the clock, so state bits update together after the clock edge. In a ripple counter, one flip-flop output clocks the next, making the change ripple through stages. Ripple counters are simple but accumulate propagation delay; synchronous designs need more logic but support faster, more coordinated changes.

Simple example

A 3-bit up-counter cycles 000, 001, 010, 011, 100, 101, 110, 111, then returns to 000.

Exam takeawayCompare how the clock reaches each stage and connect that to delay.
11

Encoders and decoders

A decoder takes an n-bit code and activates one of up to 2ⁿ output lines, often with enable controls. An encoder performs the reverse kind of task by producing a code for an active input; a priority encoder resolves cases where several inputs are active. Compare the direction of information flow and state the assumptions about active-high or active-low signals.

Simple example

A 2-to-4 decoder maps input 10₂ to output line 2 as the active line.

Exam takeawayGive input and output counts and identify which output is active for a sample code.
12

Multiplexers and demultiplexers

A multiplexer routes one of many data inputs to one output using select bits. A demultiplexer routes one input to one of several outputs. With n select bits there are 2ⁿ possible selections. A MUX can also implement Boolean functions by connecting data inputs to 0 or 1 according to the truth table.

Simple example

A 4-to-1 MUX needs two select bits; S₁S₀=11 selects I₃.

Exam takeawayConvert the select code to a line number and state the data path.
13

SR latch versus clocked flip-flop

An SR latch is level-sensitive: its stored output can respond while its enable level is active. An edge-triggered flip-flop samples at a clock transition. Both store state, but timing behavior differs. The basic SR design also has an invalid input combination, so always state the exact latch or flip-flop convention in a truth table.

Simple example

A D flip-flop changes Q at the active clock edge; a transparent latch may follow D while enabled.

Exam takeawayMention whether the device responds to a level or an edge.
14

Counter modulus and state sequence

A modulo-M counter repeats after M distinct states. A binary n-bit counter naturally has 2ⁿ states; a custom counter may use reset logic to return earlier. To design or explain one, list the states in order, mark the transition back to the start and check that unused states behave safely if required.

Simple example

A modulo-6 counter uses 000,001,010,011,100,101, then returns to 000.

Exam takeawayShow the full state sequence and explain how the reset condition is detected.
15

Half-adder and full-adder equations

For a half adder, Sum=A⊕B and Carry=AB. A full adder adds an incoming carry: Sum=A⊕B⊕Cin and Cout=AB+ACin+BCin. The sum is the parity of three inputs; the carry is 1 when at least two inputs are 1. These equations explain every row of the truth table and how adders chain.

Simple example

A=1,B=1,Cin=1 gives Sum=1 and Cout=1, representing binary 11.

Exam takeawayWrite both output equations and check a case with carry-in 1.
16

Magnitude comparator circuits

A comparator decides whether two binary values are equal, or whether one is greater or less. Starting from the most significant bit, the first position where the inputs differ determines which number is larger. Equality requires every corresponding bit to match. Multi-bit comparators combine the equality of higher positions with the comparison at the current position.

Simple example

For 1010 and 1001, the first difference is the third bit from the left: 1>0, so 1010 is larger.

Exam takeawayCompare from the most significant bit and stop at the first difference.
17

Encoder priority and invalid input cases

A basic encoder assumes exactly one input line is active. If two lines become active together, its output may be ambiguous. A priority encoder adds a defined priority order and may provide a valid bit to show whether any input is active. State the one-hot assumption before interpreting an encoder truth table.

Simple example

If D3 has higher priority than D1 and both are 1, a priority encoder outputs the code for D3.

Exam takeawayMention priority and the valid signal when the question includes simultaneous inputs.
18

Shift-register modes and applications

A shift register stores several bits and moves them one position per clock event. Serial-in/serial-out shifts a stream through; serial-in/parallel-out collects a stream for parallel reading; parallel-in/serial-out sends a stored word bit by bit; parallel-in/parallel-out loads and reads all bits together. The labels describe how data enters and leaves.

Simple example

A 4-bit SISO register can delay a serial bit stream by four clock positions.

Exam takeawayName the input/output mode and draw the direction of bit movement.
19

Synchronous and asynchronous reset

A synchronous reset changes a stored state only at the active clock edge. An asynchronous reset can change it immediately, independent of the clock. Reset initializes a circuit to a known state, which is important at startup. Timing constraints and the active polarity must be observed when connecting reset signals.

Simple example

A synchronous clear waits for the next clock; an asynchronous clear sets Q low as soon as it is asserted.

Exam takeawayState whether reset is clock-dependent and identify active-high or active-low behavior.
20

Ring and Johnson counter sequences

A ring counter circulates a bit pattern through a shift register; with one 1 among n stages it typically has n states. A Johnson counter feeds the inverted last output back to the first stage and can produce up to 2n states with n flip-flops. Both are sequence generators, so list the state cycle and check initialization.

Simple example

A 4-stage one-hot ring may cycle 1000→0100→0010→0001→1000.

Exam takeawayDraw the feedback path and verify every state in the repeating sequence.

How the unit fits together

Connect the definitions, methods and applications before you start memorizing.

Circuit design usually moves from a behavior description to a truth table, then to a smaller Boolean rule and finally to circuit blocks. Combinational circuits have no memory, so their truth table completely specifies them. Sequential circuits need a state description as well: current state, input, next state and output. A clock gives a shared moment when stored values may update. Adders illustrate how local rules connect into larger systems: a carry produced in one bit position becomes the carry-in for the next. A register is simply several storage elements working together; a counter adds a next-state rule that cycles through patterns. When comparing devices, describe what they take in, what they produce and whether they remember.

Quick recap: teach these links back

01

Combinational circuits answer now

A combinational circuit has no stored state. Its output depends only on current inputs. Adders calculate sums, multiplexers select one of several inputs, and decoders turn a coded input into one active output. To explain a circuit, name inputs and outputs, then show its truth table or Boolean rule.

02

Adders carry information between bit positions

A half adder combines two bits: XOR gives the sum bit, while AND gives the carry. It cannot accept a carry from an earlier column. A full adder accepts A, B and carry-in, and produces sum and carry-out. Chaining full adders passes each carry to the next position, like written addition.

03

Sequential circuits store a state

A flip-flop stores one bit. Its clock and input determine when that bit changes. D flip-flops copy D at the active clock event; JK and T forms provide other state changes, while SR has set/reset controls. A register combines bit-storage cells. Shift registers move bits; counters follow states. Synchronous counters share a clock, while ripple counters trigger later stages from earlier ones.

Try each task yourself first, then compare your working with the explanation.

EXAMPLE 1

Add three one-bits with a full adder

TaskFind Sum and Carry-out when A=1, B=1 and Carry-in=1.

  1. Add the three inputs as ordinary values: 1+1+1=3.
  2. Write 3 in binary: 11₂. The low bit is the sum; the next bit is the carry.
  3. Therefore Sum=1 and Carry-out=1.
Answer and reason

The full-adder output is Carry-out 1, Sum 1, giving 11₂. A half adder cannot accept the incoming carry.

EXAMPLE 2

Select a 4-to-1 multiplexer input

TaskA 4-to-1 MUX has select bits S1S0=10. Which input reaches Y?

  1. The two select bits encode a choice from 0 through 3.
  2. Binary 10₂ equals decimal 2.
  3. The selected data line is I2; its current value becomes the output Y.
Answer and reason

Y=I2. The MUX selects one input; a decoder instead activates an output line.

In combinational logic, output is a function of the current input only; examples include decoders and adders. Sequential logic includes memory or state, so output can depend on current input and the previous state; flip-flops and counters are examples. When explaining a sequential circuit, identify its state variable, clock behaviour and next-state rule.

Important questions with model answers  Question: Compare a half adder and a full adder.  Model answer  A half adder adds two one-bit inputs and produces sum and carry. It has no carry-in input, so it cannot directly handle the carry from a previous stage. A full adder adds A, B and carry-in, producing sum and carry-out. Full adders can be connected in a chain to add multi-bit binary numbers.  Question: What is the difference between combinational and sequential logic?  Model answer  In combinational logic, output is a function of the current input only; examples include decoders and adders. Sequential logic includes memory or state, so output can depend on current input and the previous state; flip-flops and counters are examples. When explaining a sequential circuit, identify its state variable, clock behaviour and next-state rule.
