Matrix algebra

A matrix is a number table that organizes systems of equations and transformations. This unit builds from determinants and inverses to rank, eigenvalues, Cramer's rule and the Cayley-Hamilton idea.

PICTURE IT

A matrix is a tidy number table. Its rows and columns help us solve several equations together.

A matrix is a tidy grid of numbers. A determinant is one signal about whether that grid can be reversed to recover its input.

  • Calculate a 2×2 determinant and inverse when valid.
  • Find rank through row reduction and solve systems with Cramer's rule.

01

Determinants and invertibility

For a 2×2 matrix [[a,b],[c,d]], det(A)=ad−bc. A nonzero determinant means the square matrix is invertible; zero means its rows or columns are dependent and the matrix is singular. Determinants also appear in solving systems and finding eigenvalues. Keep the sign and order of entries consistent during calculation.

Simple example

For [[2,1],[1,2]], determinant is 2×2−1×1=3, so an inverse exists.

Exam takeawayCalculate the determinant first and use it to justify whether an inverse exists.
02

Inverse of a 2×2 matrix

For A=[[a,b],[c,d]] with nonzero determinant, A⁻¹=(1/(ad−bc))[[d,−b],[−c,a]]. The diagonal entries swap and the off-diagonal entries change signs, then the matrix is divided by the determinant. The inverse reverses the transformation because AA⁻¹=I. Always verify by multiplication when time permits.

Simple example

For [[2,1],[1,2]], det=3 and inverse is (1/3)[[2,−1],[−1,2]].

Exam takeawayShow determinant, adjugate pattern and scalar division.
03

Rank and row reduction

Rank is the number of linearly independent rows or columns; row rank and column rank are equal. To find it, use elementary row operations to reduce the matrix to echelon form and count nonzero rows. Rank describes how much independent information a matrix contains and helps analyze whether a system has enough independent equations.

Simple example

If reduction leaves two nonzero rows, the rank is 2.

Exam takeawayShow row operations clearly and count nonzero rows in the reduced form.
04

Eigenvalues and eigenvectors

An eigenvector is a nonzero vector whose direction is unchanged by a square matrix; the matrix scales it by its eigenvalue λ: Av=λv. Rearranging gives (A−λI)v=0. A nonzero solution exists when det(A−λI)=0; solve this characteristic equation for eigenvalues, then solve for each corresponding eigenvector.

Simple example

For [[2,1],[1,2]], eigenvalues are 3 and 1; directions (1,1) and (1,−1) are corresponding eigenvectors.

Exam takeawayFind roots of det(A−λI), then solve the homogeneous system for each λ.
05

Cramer's rule

Cramer's rule solves a square linear system when the determinant D of the coefficient matrix is nonzero. To find xᵢ, replace the i-th coefficient column with the constants column to get Dᵢ, then xᵢ=Dᵢ/D. It is convenient for small systems but requires a nonzero determinant and becomes inefficient for large systems.

Simple example

For x+y=5 and 2x−y=1, D=−3, Dₓ=−6, Dᵧ=−9, so x=2 and y=3.

Exam takeawayShow D, each replaced-column determinant and the final check.
06

Cayley-Hamilton theorem

The Cayley-Hamilton theorem states that every square matrix satisfies its own characteristic polynomial. If the characteristic polynomial is p(λ), then substituting A gives p(A)=0. This can reduce high powers of a matrix to lower powers. If A is invertible, the relation can also be rearranged to express A⁻¹ in terms of lower powers, following the exact polynomial.

Simple example

If p(λ)=λ²−3λ+2, the theorem gives A²−3A+2I=0 for that matrix.

Exam takeawayFind the characteristic polynomial first, then replace λ with A and simplify.
07

Determinants and singular matrices

The determinant summarizes important information about a square matrix. If det(A) is nonzero, the matrix is invertible and its rows or columns are independent; if det(A)=0, it is singular and has no inverse. For larger matrices, expansion by a row or column uses signed minors; choose a row with zeros when possible to reduce work.

Simple example

For [[2,1],[4,2]], det=2·2−1·4=0, so the matrix is singular.

Exam takeawayShow the determinant calculation before deciding whether an inverse or Cramer's rule applies.
08

Row reduction and rank

Elementary row operations preserve the solution structure and lead toward echelon form. Swap rows, multiply a row by a nonzero constant or add a multiple of one row to another. The rank is the number of pivots or nonzero rows in echelon form. A zero row signals dependent information, not necessarily that the system has no solution.

Simple example

If reduction produces two pivots and one zero row, the matrix rank is 2.

Exam takeawayRecord each row operation clearly and count pivots, not original nonzero rows.
09

Eigenvalues and eigenvectors

An eigenvector is a nonzero direction that a square matrix scales without changing its direction. The scale factor is the eigenvalue λ, found by solving det(A−λI)=0. For each root, solve (A−λI)v=0 to find the eigenvectors. Eigenvectors may be multiplied by any nonzero constant, so give a valid nonzero vector and verify the equation.

Simple example

For A=[[2,0],[0,3]], eigenvalues are 2 and 3 with eigenvectors along the first and second coordinate axes.

Exam takeawayFind λ first, then solve the homogeneous system and substitute to verify.
10

Using Cayley–Hamilton to reduce powers

Cayley–Hamilton states that every square matrix satisfies its own characteristic polynomial. If p(λ)=λ²−3λ+2 for a matrix A, then A²−3A+2I=0. Rearranging can reduce higher powers or, when the constant term is nonzero, produce an inverse relation. Keep the identity matrix visible; scalar terms become multiples of I.

Simple example

From A²−3A+2I=0, infer A²=3A−2I.

Exam takeawayWrite the characteristic polynomial, replace λ with A and keep scalar terms attached to I.

How the unit fits together

Connect the definitions, methods and applications before you start memorizing.

Matrix problems reward a repeatable setup. Check dimensions first, then identify the requested operation. The determinant indicates whether a square matrix can be inverted; rank counts independent information; eigenvectors reveal directions that a linear transformation scales without turning. For a system of equations, Cramer's rule replaces one coefficient column at a time, but only when the determinant is nonzero. Cayley-Hamilton connects a matrix to its characteristic polynomial and lets higher powers be reduced. Keep notation consistent: I is the identity matrix, λ is a scalar eigenvalue, and an eigenvector must be nonzero. After solving a system or finding an inverse, verify by substitution or multiplication.

Quick recap: teach these links back

01

Determinants tell when a square matrix is invertible

For [[a,b],[c,d]], det=ad−bc. If it is zero, the rows or columns are dependent and no inverse exists. If nonzero, the inverse is 1/(ad−bc) times [[d,−b],[−c,a]]. Compute the determinant before attempting an inverse.

02

Rank measures independent information

The rank is the number of linearly independent rows or columns. Row reduction is a reliable way to find it: use elementary row operations to reach echelon form and count nonzero rows. Rank helps show whether equations contain independent information or some rows repeat others.

03

Eigenvalues and solution rules reveal structure

An eigenvalue λ satisfies det(A−λI)=0; a corresponding nonzero eigenvector v satisfies (A−λI)v=0. Cramer's rule solves a square system using determinants when the coefficient determinant is nonzero. Cayley-Hamilton says a square matrix satisfies its own characteristic polynomial, helping simplify matrix powers or derive an inverse when conditions allow.

EXAMPLE 1

Find the eigenpairs of a symmetric matrix

TaskFor A=[[2,1],[1,2]], find the eigenvalues and one eigenvector for each.

  1. Compute det(A−λI)=|(2−λ),1;1,(2−λ)|=(2−λ)²−1.
  2. Set it to zero: (2−λ−1)(2−λ+1)=0, giving λ=3 or λ=1.
  3. For λ=3, equations imply x=y, so v=(1,1) works.
  4. For λ=1, equations imply x=−y, so v=(1,−1) works.
Answer and reason

Eigenvalues 3 and 1 with corresponding eigenvectors (1,1) and (1,−1); any nonzero scalar multiples also work.

EXAMPLE 2

Solve with Cramer's rule

TaskSolve x+y=5 and 2x−y=1.

  1. Coefficient determinant D=|1,1;2,−1|=−3.
  2. Replace x column with constants: Dₓ=|5,1;1,−1|=−6, so x=Dₓ/D=2.
  3. Replace y column: Dᵧ=|1,5;2,1|=−9, so y=Dᵧ/D=3.
  4. Substitute: 2+3=5 and 4−3=1.
Answer and reason

x=2 and y=3. Nonzero D confirms Cramer's rule applies.

QUESTION 1Find the eigenvalues and eigenvectors of [[2,1],[1,2]].+

Compute det(A-lambda I) = (2-lambda)^2-1 = 0. This gives lambda=3 or lambda=1. For lambda=3, the equations reduce to x=y, so one eigenvector is (1,1). For lambda=1, they reduce to x=-y, so one eigenvector is (1,-1). Any non-zero scalar multiple of either vector is also an eigenvector.

QUESTION 2Solve x+y=5 and 2x-y=1 using Cramer's rule.+

The coefficient determinant is D = |1 1; 2 -1| = -3. D_x = |5 1; 1 -1| = -6, so x=D_x/D=2. D_y = |1 5; 2 1| = -9, so y=D_y/D=3. Check both original equations: 2+3=5 and 4-3=1.

WORK IT THROUGH

Solve x+y=5 and 2x−y=1, then verify.

  1. Add the equations: 3x=6, so x=2.
  2. Substitute into x+y=5: y=3.
  3. Check both: 2+3=5 and 4−3=1. With Cramer's rule, show D, Dₓ and Dᵧ before dividing.
