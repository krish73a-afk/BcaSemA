Counting & recurrences

Counting turns “how many?” into a choice of rule. Recurrences define a sequence using earlier terms. This unit helps you decide whether order matters, count arrangements correctly and solve simple recurrence patterns.

PICTURE IT

If you have 3 shirts and 2 hats, you can make 3 × 2 outfits. Counting is organized choosing.

If you choose a shirt and then a hat, each shirt can pair with each hat. Counting is careful bookkeeping so no choice is missed or counted twice.

BY THE END, YOU CAN

  • Choose permutations or combinations based on whether order matters.
  • Apply addition, multiplication and pigeonhole principles.
  • Solve a simple constant-coefficient recurrence using its characteristic equation.

LESSON PATH

Build the idea step by step

Read one card, say it back in your own words, then try the example.

01

Count choices with the right principle

Use multiplication for successive independent choices: 3 shirts and 2 hats give 3×2 outfits. Use addition for alternatives that cannot happen together, adding their counts. A permutation counts ordered selections; a combination counts selections where order does not matter.

02

Permutations, combinations and pigeonholes

For n distinct items chosen r at a time, nPr=n!/(n−r)!; nCr=n!/[r!(n−r)!]. The pigeonhole principle says more objects than boxes forces a box to hold at least two. The binomial theorem expands (x+y)^n using combination coefficients; each coefficient counts how many ways to choose that number of y factors.

03

A recurrence builds each term from earlier terms

A recurrence defines terms using previous terms and needs initial values to identify the sequence. For a linear recurrence with constant coefficients, try a term shaped like r^n to form a characteristic equation. Solve for roots, write a general combination of root terms, then use initial values to determine constants.

✦

WORK IT THROUGH

Count four-letter arrangements from the eight different letters of COMPUTER.

  1. Order matters because ABCD and BACD are different arrangements, so use a permutation.
  2. 8P4 = 8×7×6×5 = 1,680.
  3. If you were only choosing four letters and order did not matter, you would use 8C4 instead.

WATCH OUT FOR

Easy mix-ups

  • Ask whether order matters before choosing nPr or nCr.
  • If items repeat, the distinct-item formula may need adjustment.
  • A recurrence needs initial values as well as its rule.

CORE IDEAS TO REMEMBER
01

Use permutations when order matters: nPr = n!/(n-r)!; use combinations when order does not: nCr = n!/(r!(n-r)!).

02

For distinct letters in COMPUTER, selecting and arranging four gives 8P4 = 8 x 7 x 6 x 5 = 1680.

03

The pigeonhole principle says that placing more objects than boxes forces at least one box to hold two or more objects.

04

For a linear recurrence with constant coefficients, form the characteristic equation and use its roots to construct the sequence solution.

05

The binomial theorem is (x+y)^n = sum from r=0 to n of nCr x^(n-r)y^r.

IMPORTANT QUESTIONS · TAP TO REVEAL MODEL ANSWERS
QUESTION 1How many distinct four-letter arrangements can be made from COMPUTER?+

The eight letters in COMPUTER are all different. Since order matters, use a permutation: 8P4 = 8!/(8-4)! = 8 x 7 x 6 x 5 = 1680. If a question allows repeated letters, or includes duplicate letters in the source word, adjust the counting method before calculating.

QUESTION 2Solve a simple recurrence: a(n)=3a(n-1)-2a(n-2), with a(0)=1 and a(1)=3.+

Assume a(n)=r^n. The characteristic equation is r^2-3r+2=0, so (r-1)(r-2)=0 and the roots are 1 and 2. Thus a(n)=A+B(2^n). From a(0)=1, A+B=1; from a(1)=3, A+2B=3. Therefore B=2 and A=-1, giving a(n)=2^(n+1)-1. Check: a(0)=1 and a(1)=3.
