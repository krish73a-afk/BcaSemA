Number problems & statistics

Digits and running totals are small patterns with many exam questions. This unit uses division and remainder to inspect digits, then applies loops to number properties and simple statistics.

01

Extract and reverse decimal digits

For a positive integer n, n%10 gives the last decimal digit and integer n/10 removes it. Repeat until n becomes zero to process digits from right to left. To construct the reverse, update reverse=reverse×10+digit. Save the original value before changing n if it will be needed later.

Simple example

582 yields digits 2, 8, 5; reverse builds 0→2→28→285.

Exam takeawayShow initialization and both remainder/division operations.
02

Palindrome and Armstrong checks

A number is a palindrome if it reads the same forward and backward; compare the reversed value with the saved original. A three-digit Armstrong number equals the sum of the cubes of its digits. The broader n-digit definition raises each digit to the number-of-digits power, so follow the version specified by the question. Be explicit about valid input and zero handling.

Simple example

153 = 1³+5³+3³=153, so it is a three-digit Armstrong number.

Exam takeawaySave the original and show each digit's contribution.
03

Prime numbers and efficient divisor checks

A prime is an integer greater than 1 with exactly two positive divisors: 1 and itself. Zero, one and negative values are not prime. To test n, check possible divisors from 2 through the square root; if a larger factor exists, it must pair with a smaller one. Stop as soon as a divisor is found.

Simple example

For 29, test divisors through √29 (about 5.4): 2, 3, 4 and 5 do not divide it, so 29 is prime.

Exam takeawayHandle n<=1 first, then show the divisor range and result.
04

Factorial and boundary cases

For a non-negative integer n, n!=n×(n−1)×…×1, with 0!=1. An iterative solution initializes product=1 and multiplies from 1 through n. A recursive solution uses 0 as the base case. Factorials grow quickly, so a chosen integer type may overflow for modest n; state the input range if relevant.

Simple example

5!=1×2×3×4×5=120; 0! is 1 by definition.

Exam takeawayInclude the 0! base case and explain the loop or recurrence.
05

Streaming statistics and safe averages

For a stream of values, update count and sum for each valid item; maintain minimum and maximum as values arrive. A sentinel ends the stream and must not be counted. Calculate average only if count>0, otherwise division by zero occurs. Initialize minimum and maximum from the first real value rather than an arbitrary constant when the value range is unknown.

Simple example

For 4, 9, 2: count=3, sum=15, minimum=2, maximum=9 and average=5.

Exam takeawayShow variable initialization, sentinel exclusion and the count check.
06

Extract digits with remainder and division

For a nonnegative integer, n%10 returns the last decimal digit and integer division n/10 removes it. Repeating these operations processes the number from right to left. Save the original value before modifying n if a later comparison needs it. Take care with zero and negative values because their handling depends on the problem's definition.

Simple example

For 472: 472%10=2; then 472/10=47; next digits are 7 and 4.

Exam takeawayShow each remainder, updated number and any saved original.
07

Prime testing through the square root

A prime number greater than 1 has exactly two positive divisors. If n has a factor larger than √n, it must also have a matching factor smaller than √n. Therefore, testing divisors through √n is enough. Handle n<2 separately and stop when the divisor squared exceeds n to avoid floating-point square-root issues.

Simple example

For 29, test 2, 3, 4 and 5 because 6²>29; none divides, so 29 is prime.

Exam takeawayExplain the paired-factor reason for the square-root limit.
08

Armstrong numbers and digit powers

An Armstrong number equals the sum of each digit raised to the number of digits. The common three-digit version uses cubes, but the general definition uses the digit count. Extract each digit, raise it to the required power and accumulate the sum. Keep the original number for the final comparison.

Simple example

153 has three digits and 1³+5³+3³=1+125+27=153, so it is an Armstrong number.

Exam takeawayState whether the question uses the three-digit cube rule or the general definition.
09

Factorials, statistics and safe ranges

Factorial multiplies integers from 1 through n, with 0!=1. Its value grows quickly and can exceed an integer type, so consider the input limit. For a stream of values, maintain count, sum, minimum and maximum; calculate an average only when count is greater than zero. A wider type may be needed for the sum.

Simple example

For 4, 8 and 12, count=3, sum=24 and average=24/3=8.

Exam takeawayShow initialization, update rule and checks for empty input or overflow.
10

Palindrome testing and reverse arithmetic

To test a numeric palindrome, save the original number, build its reverse with reverse=reverse×10+digit and compare the two values. Decide how to handle negatives and trailing zeroes. A string palindrome test has different rules because it can preserve leading zeroes and compare characters directly.

Simple example

For 121: reverse becomes 1, then 12, then 121; it equals the saved original.

Exam takeawayShow the digit trace and explain the chosen sign/zero convention.
11

Factorial recursion and iteration

Factorial can be computed iteratively with a running product or recursively from n!=n×(n−1)!, with 0!=1. Both methods need a valid domain, usually nonnegative integers. Iteration uses constant extra space; recursion uses call-stack space. The result grows quickly, so choose a data type and input limit that avoid overflow.

Simple example

5!=5×4×3×2×1=120; 0!=1 by definition.

Exam takeawayState the base case or initialization, update and overflow limitation.
12

Running averages without storing all values

A streaming average can be computed using count and sum, so the program need not keep every input value. Initialize both to zero, update them for valid observations and divide only after confirming count>0. For large data, use a type wide enough for the total and consider numeric precision.

Simple example

Read 6, 8 and 10: count=3, sum=24, average=8.

Exam takeawayShow the update and protect against an empty input stream.
13

Integer overflow and type selection

Integer types have finite ranges. Overflow can produce an incorrect result, especially in factorials, digit powers and accumulated totals. Estimate the maximum intermediate value, not just the final displayed value, and choose a suitable type. If the required range exceeds the type, the algorithm needs a different representation or explicit overflow handling.

Simple example

A small integer type may hold 100, but 100! is far beyond ordinary machine integers.

Exam takeawayExplain the range requirement and state how overflow is prevented or detected.
14

Digit extraction with quotient and remainder

For a positive integer n, n mod 10 gives the last decimal digit and floor(n/10) removes that digit. Repeating the process scans digits from right to left. Handle zero and negative input explicitly, because a loop conditioned on n>0 skips zero and sign handling can vary by language.

Simple example

For 472: remainders are 2, 7, 4 while quotients are 47, 4, 0.

Exam takeawayTrace remainder and quotient updates and state how zero or negative input is handled.
15

Prime testing and loop bounds

A prime is an integer greater than 1 with exactly two positive divisors. To test n, check divisors from 2 through floor(√n); if a factor larger than √n existed, its paired factor would be smaller. Handle n<2 first, then stop as soon as a divisor is found.

Simple example

For 29, test 2, 3, 4 and 5 only; none divides, so 29 is prime.

Exam takeawayExplain the square-root bound and exclude 0 and 1 from the prime category.
16

Factorial, divisors and input limits

Factorial n! is the product 1×2×…×n, with 0!=1 by definition. Its value grows rapidly, so large inputs may overflow fixed-size integer types. A divisor test should stop at √n for the same factor-pair reason used in prime testing. Validate that the input is a nonnegative integer.

Simple example

5!=5×4×3×2×1=120 and 0!=1; a 32-bit integer cannot hold arbitrarily large factorials.

Exam takeawayGive the base case and discuss input validity or overflow where relevant.
17

Descriptive statistics: mean, median, mode

The mean is total divided by count and is sensitive to extreme values. The median is the middle ordered value (or average of the two middle values) and is more resistant to outliers. The mode is the most frequent value; a dataset may have one, several or no repeated mode depending on convention.

Simple example

For 2,3,3,12, mean=5, median=3 and mode=3, showing the effect of the high value 12.

Exam takeawaySort the data before finding the median and state what each measure describes.
18

Range, variance and standard deviation

Range is maximum minus minimum and shows total spread but uses only two values. Variance averages squared deviations from the mean; standard deviation is its square root and is in the original units. Population and sample formulas differ in denominator, so select the one stated by the question.

Simple example

For 2,4,6, mean=4; squared deviations are 4,0,4, giving population variance 8/3 and standard deviation √(8/3).

Exam takeawayShow the mean, deviations, squared deviations and whether n or n−1 is used.
19

Frequency tables and grouped data

A frequency table counts how often values or class intervals occur. Cumulative frequency adds counts up to each class and helps locate medians or percentiles. For grouped data, midpoints support an approximate mean; the result is an estimate because individual observations are not known.

Simple example

Intervals 0–9, 10–19 with frequencies 3 and 2 have midpoints 4.5 and 14.5; estimated mean=(3·4.5+2·14.5)/5=8.5.

Exam takeawayLabel class boundaries, frequency and cumulative frequency, and state when a result is approximate.

How the unit fits together

Connect the definitions, methods and applications before you start memorizing.

Digit algorithms are based on place value. Division by ten removes the last decimal digit, while remainder by ten extracts it. The reverse construction multiplies the current answer by ten to make room for the next digit. Save the original before mutating the working copy. Number-property algorithms reuse this digit loop, but their definitions differ: palindrome compares reverse with original, Armstrong sums a power of each digit, and prime testing checks divisors. Statistics algorithms use a different running state: count, sum, minimum and maximum. Initialize min and max from the first valid item when the range is unknown, and check that count is not zero before using an average.

01

Take a number apart one digit at a time

For positive integer n, n%10 gives its last digit and integer n/10 removes it. Repeating examines digits from right to left. To reverse a number, update reverse=reverse×10+digit. Save the original first if you will compare the transformed number later.

02

Common number properties are loop patterns

A palindrome equals its reverse. A three-digit Armstrong number equals the sum of the cubes of its digits; for more digits, follow the definition in the question. A prime greater than 1 has exactly two positive divisors; checking candidates only through the square root is enough. Factorial multiplies positive integers down to 1, with 0!=1.

03

Statistics need running state and a safe count

For a stream of values, keep count, sum, minimum and maximum as each arrives. A sentinel can stop input but should not be included. Compute average=sum/count only after checking count>0. Choose data types that can hold the possible sum or factorial result.

EXAMPLE 1

Check whether 153 is a three-digit Armstrong number

TaskUse the sum of the cubes of its digits.

  1. Extract digits: 153%10=3, then 15%10=5, then 1%10=1.
  2. Cube each digit and add: 3³+5³+1³=27+125+1=153.
  3. Compare the sum with the saved original number.
  4. They match, so 153 is a three-digit Armstrong number.
Answer and reason

153 satisfies this three-digit definition. State the definition in the answer.

EXAMPLE 2

Test 29 for primality

TaskUse the square-root bound.

  1. 29 is greater than 1, so continue.
  2. The square root of 29 is about 5.4; only test integer divisors 2 through 5.
  3. None of 2, 3, 4 or 5 divides 29.
  4. No divisor was found, so 29 is prime.
Answer and reason

If a composite factor existed above √29, its paired factor would be below √29.

QUESTION 1How does a digit-reversal algorithm work?+

Save the original number if it is needed later. Set reverse to zero. While n is greater than zero, take digit=n%10, update reverse=reverse*10+digit, then set n=n/10 using integer division. For example, 582 becomes 2, then 28, then 285. For inputs that can be negative, decide whether to preserve the sign. For inputs ending in zero, the numerical reverse drops leading zeros, which is usually correct for integer output.

QUESTION 2What is sentinel-controlled repetition? Give a safe average calculation.+

A sentinel is a value that ends input and is not included in the data. Set count=0 and sum=0. Read a value; while it is not the sentinel, add it to sum, increase count and read the next value. Before calculating average, check count>0; otherwise division by zero would occur. A sentinel must be chosen so it cannot be mistaken for a valid data item, or the input format must provide another way to indicate the end.

WORK IT THROUGH

Reverse 582 using integer steps.

  1. Start reverse=0. Take digit=582%10=2; reverse=0×10+2=2; remaining n=58.
  2. Take 8; reverse=2×10+8=28; remaining n=5.
  3. Take 5; reverse=28×10+5=285; remaining n=0. The reverse is 285.
