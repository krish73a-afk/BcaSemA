Sensible writing styles

Different writing tasks need different shapes. A description paints a picture, a definition explains a term, and a classification sorts a topic into groups. This unit helps you match the structure to the question.

PICTURE IT

Choose your writing shape: tell what something is, sort it into groups, or paint a picture with words.

Describe a toy and show what it looks like. Define it and say what makes it that kind of toy. Classify toys and explain the rule used to sort them.

BY THE END, YOU CAN

  • Choose descriptive, definitional or classificatory structure for a prompt.
  • Build an introduction that points to the topic and direction.
  • Use paragraphs and a conclusion that fulfill the task.

8 CONCEPTS

01

Descriptive writing

Descriptive writing helps a reader picture a person, place, object or event. Select details that matter to the purpose, then arrange them by space, sequence or importance. Specific observations are stronger than a long list of general adjectives. Use sensory detail where it helps, while keeping the description organized and relevant.

Simple example

Describe a classroom from the doorway inward: rows of desks, a bright board and the sound of a fan.

Exam takeawayState the order you use and include selected details that support the subject.
02

Definitional writing

A definition identifies a term and explains the features that distinguish it from related ideas. A useful paragraph can give the category, distinguishing features, examples and significance. Broad terms such as success need a clear scope because different people may define them differently. Avoid a circular definition that merely repeats the word.

Simple example

Define a “reliable source” by its evidence, author expertise, transparency and relevance to the question.

Exam takeawayDefine the term, explain its boundaries and support it with an example.
03

Classification writing

Classification divides a larger group into categories using a stated principle. Begin by naming the whole group and the basis for sorting it. Explain each category with parallel wording and an example. Categories should not overlap confusingly or leave out a major group if the task expects a complete classification.

Simple example

Classify revision by reviewing content, practising retrieval and applying ideas to new problems.

Exam takeawayState the sorting rule first, then describe each group consistently.
04

Introductions, body paragraphs and conclusions

An introduction presents the topic and direction, often with a central claim or definition. Body paragraphs develop parts of that direction, each with a clear role and supporting detail. A conclusion answers the prompt and closes the discussion; it can restate the main idea in fresh words and explain why it matters. Do not introduce a new major argument at the end.

Simple example

An essay on success might define the term, discuss two measures of it, then conclude with the definition supported by the examples.

Exam takeawayMake sure every section helps answer the prompt from beginning to end.
05

Descriptive writing with selected detail

Description helps a reader picture a person, place, object or event. Choose a few precise details that support the main impression instead of listing every visible thing. Sensory words can help, but each detail should serve a purpose and the sequence should guide the reader through the scene.

Simple example

Describe a busy station through the echoing announcement, the moving queue and the bright departure board.

Exam takeawayUse precise details and an order such as near-to-far or first-to-last.
06

Definition writing: class and difference

A clear definition often names the general class first, then explains the features that distinguish the term from others in that class. Avoid defining a word by repeating it. If the concept is technical, give a plain-language explanation and one boundary or example so the reader knows what belongs and what does not.

Simple example

A compiler is a program that translates source code into another form, often machine code, before execution.

Exam takeawayState the class, defining feature and a short example or contrast.
07

Classification and parallel categories

Classification groups items using one clear basis, such as purpose, size or process. Categories should not overlap confusingly and should be parallel: if one category describes function, the others should also describe function. State the organizing rule before listing groups and use examples to show where items belong.

Simple example

Classify communication by direction: one-way, two-way or group communication.

Exam takeawayName the basis of classification and make the categories consistent.
08

Essay structure and paragraph unity

An introduction gives context and a focused central claim. Each body paragraph develops one supporting point with explanation and evidence. A conclusion brings the argument together and shows why it matters; it should not simply repeat every sentence. Planning a short outline prevents a promising introduction from leading to unrelated paragraphs.

Simple example

For an essay on reading, plan one paragraph on vocabulary, one on knowledge and one on concentration.

Exam takeawayMake each paragraph support the central claim and use transitions between points.

How the unit fits together

Connect the definitions, methods and applications before you start memorizing.

The first question in a writing task is “what kind of explanation does the reader need?” Description organizes observable details; definition clarifies a concept's boundaries; classification shows how a group is divided. A prompt can combine modes, but one should guide the structure. State the organizing principle early so the reader knows how to follow. In classification, categories should be parallel and based on one rule. In a definition, examples make an abstract term concrete while boundaries prevent the term from becoming too broad. Introductions point toward the answer; conclusions close the reasoning instead of opening a new topic.

Quick recap: teach these links back

01

Description gives a clear picture

A description selects details and orders them so the reader can imagine the subject. Move from left to right, near to far, step by step through time, or from the most important detail to smaller ones. Good description uses details that support the purpose instead of listing everything.

02

Definition explains a term's boundaries

A definition names the term, explains its distinguishing features and may give examples. It can clarify what the term is not when nearby ideas are easily confused. For a broad word such as success, explain the sense you mean and support it with examples rather than assuming everyone defines it alike.

03

Classification groups items by one clear rule

State the group and the principle used to divide it, then explain each category with examples. Categories should be clear and not overlap confusingly. An introduction names the topic and direction; a conclusion should answer the prompt and close the argument, not introduce an unrelated idea.

EXAMPLE 1

Write a useful definition

TaskDefine “reliable study source.”

  1. Name its general category: a source of information used for learning.
  2. Give distinguishing features: author or institution can be checked, evidence is shown, and the material fits the question.
  3. Add a brief example of a source that meets the features.
  4. Clarify that reliability is about evidence and purpose, not appearance alone.
Answer and reason

A definition is specific enough to distinguish the term from a source that merely looks professional.

EXAMPLE 2

Classify ways to practise

TaskCreate a classification using one clear principle.

  1. Name the whole group: ways of practising a subject.
  2. State the basis: what the learner does with information.
  3. Make parallel categories: review content, retrieve it from memory, apply it to a new problem.
  4. Give one example for each and note that learners may combine the categories.
Answer and reason

The categories follow one rule and have examples, so the reader can compare them.

PAGE 7 · EXAM ANSWER CLINIC

Practise the questions in your study guide

Write your answer first. Then reveal the model and compare the concepts, order, working and example.

Before you finish an answer
  1. Answer the command word directly.
  2. Define the key term or state the rule.
  3. Show the steps, evidence or comparison.
  4. Give a relevant example and a clear final result.
QUESTION 1How should a definitional essay be organized?+

Start with a clear definition of the term. Explain its main features, boundaries and significance. Add examples and, where useful, distinguish it from a related term. Organize the body into paragraphs with one function each. The conclusion should restate the meaning in a fresh way and explain why it matters. For a broad concept such as success, avoid defining it only as wealth or fame.

QUESTION 2How do you write a classification paragraph?+

Name the whole group and state the basis for dividing it. Introduce each category and describe its defining features. Use parallel wording so categories are easy to compare, and provide an example for each. Make sure the categories do not overlap in a confusing way. End by explaining what the classification helps the reader understand.

✦

WORK IT THROUGH

Classify ways students revise.

  1. State the grouping rule: students can review content, practise retrieval, or apply ideas to problems.
  2. Explain each type and give an example: reread a concept map, answer questions from memory, or solve a new problem.
  3. Close by explaining that students often combine the three methods.

WATCH OUT FOR

Easy mix-ups

  • Do not mix several classification rules in one list.
  • A definition needs distinguishing features, not just a synonym.
  • A conclusion should connect to the prompt and the answer you developed.

EXAM ANSWER BUILDER

Show your thinking

  1. Start with the key definition or rule.
  2. Show each step, label and example clearly.
  3. Finish with the result and a one-line reason.

If the question says “compare,” write both sides using the same points.
