Graph theory

Graph theory turns a map of connections into a precise object. This unit distinguishes paths, cycles, trees, Euler routes and Hamiltonian routes, then uses rules to reason about networks and planar drawings.

LESSON PATH

Build the idea step by step

Read one card, say it back in your own words, then try the example.

01

Graphs model relationships

A graph has vertices and edges. A path follows connected edges; a cycle returns to its start. The degree of a vertex is the number of edges touching it. Graphs can model roads, computer networks or relationships without needing real distances.

02

Trees connect without loops

A tree is connected and has no cycles. With n vertices it has n−1 edges: each new vertex needs one edge to remain connected, and an extra edge would create a cycle. A spanning tree uses every vertex of a connected graph with the minimum number of edges needed for connectivity.

03

Euler asks about edges; Hamilton asks about vertices

An Euler circuit uses every edge exactly once and returns to its start; in a connected undirected graph, each vertex must have even degree. A Hamiltonian cycle visits each vertex exactly once before returning and need not use every edge. For a connected planar graph, V−E+F=2, where F includes the outside region.

✦

WORK IT THROUGH

A connected tree has 6 vertices. How many edges?

  1. Use the tree rule E=n−1.
  2. Substitute n=6: E=6−1=5.
  3. Adding another edge between existing vertices creates a cycle, so the result is no longer a tree.

WATCH OUT FOR

Easy mix-ups

  • Euler conditions concern edges; Hamiltonian conditions concern vertices.
  • A spanning tree includes all vertices but only enough edges to connect them.
  • Count the outside region when using V−E+F=2.

CORE IDEAS TO REMEMBER
01

A graph has vertices and edges. A path follows adjacent vertices; a cycle returns to its start without repeating intermediate vertices.

02

A tree is connected and acyclic. A tree with n vertices has n-1 edges.

03

A spanning tree connects every vertex of a connected graph using the fewest possible edges and contains no cycle.

04

An Euler circuit uses every edge once and returns to its starting vertex; a Hamiltonian cycle visits every vertex once and returns.

05

For a connected planar graph, V-E+F=2, where F counts regions including the outside face.

IMPORTANT QUESTIONS · TAP TO REVEAL MODEL ANSWERS
QUESTION 1Distinguish Euler and Hamiltonian circuits.+

An Euler circuit uses every edge exactly once and returns to its start; vertices may be visited more than once. A Hamiltonian cycle visits each vertex exactly once before returning to its start; it does not require using every edge. The distinction is whether the condition concerns edges or vertices. For a connected undirected graph, an Euler circuit exists when every vertex has even degree.

QUESTION 2What is a spanning tree? Explain why it has n-1 edges.+

A spanning tree is a connected, cycle-free subgraph containing all vertices of a connected graph. A basic tree with one vertex has zero edges. Each time a new vertex is added while preserving connectivity and avoiding cycles, exactly one edge is added. Therefore a tree with n vertices has n-1 edges. A spanning tree is useful for connecting network sites with no redundant links.
