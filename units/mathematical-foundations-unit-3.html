Graph theory

Graph theory turns a map of connections into a precise object. This unit distinguishes paths, cycles, trees, Euler routes and Hamiltonian routes, then uses rules to reason about networks and planar drawings.

01

Vertices, edges, degree and graph types

A graph consists of vertices (nodes) and edges (connections). The degree of a vertex is the number of incident edges; a loop contributes twice in common undirected-graph conventions. Graphs may be directed or undirected, simple or allow multiple edges, connected or disconnected. A diagram makes these properties visible, but use the definitions when giving an answer.

Simple example

In a road network, intersections are vertices and road segments are edges.

Exam takeawayDefine the graph's objects and state whether edges have direction.
02

Paths, trails and cycles

A walk is a sequence of adjacent vertices and edges. A trail does not repeat edges; a path usually does not repeat vertices. A cycle returns to its starting vertex without repeating intermediate vertices. Terminology can vary slightly by text, so use the course's definitions and show the route on a diagram.

Simple example

A-B-C is a path if edges AB and BC exist; A-B-C-A is a cycle if CA also exists.

Exam takeawayMark the route and say what may or may not repeat.
03

Trees and the n−1 edge rule

A tree is a connected, acyclic graph. Every pair of vertices has exactly one path between them. A tree with n vertices has n−1 edges: adding a new vertex while preserving connectivity and avoiding cycles requires one new edge. Conversely, a connected graph with n−1 edges is a tree. The rule is a quick check, not a substitute for verifying connectedness when needed.

Simple example

A tree with 6 vertices has 5 edges.

Exam takeawayState both properties—connected and acyclic—before using the edge count.
04

Spanning trees

A spanning tree is a subgraph that includes every vertex of a connected graph but has no cycles. It keeps just enough edges to maintain connectivity, so with n vertices it has n−1 edges. Spanning trees are useful for connecting network locations without redundant links. A graph can have several different spanning trees.

Simple example

A network with roads forming loops can remove some roads and still connect every town as a spanning tree.

Exam takeawayShow that every vertex is included, the subgraph is connected and there are no cycles.
05

Euler and Hamiltonian circuits

An Euler circuit uses every edge exactly once and returns to its starting vertex; vertices may be revisited. For a connected undirected graph, it exists exactly when every vertex has even degree. A Hamiltonian cycle visits every vertex exactly once before returning to its start; it does not have to use every edge. Euler is about edges; Hamiltonian is about vertices.

Simple example

A route that checks every road once is Euler-like; a tour that visits every city once is Hamiltonian-like.

Exam takeawayUnderline whether the condition refers to edges or vertices.
06

Planar graphs and Euler's formula

A planar graph can be drawn on a plane without edges crossing except at shared vertices. For a connected planar graph, V−E+F=2, where V is vertices, E edges and F faces, including the unbounded outside region. Different drawings of the same planar graph can have different-looking regions, but the formula still holds.

Simple example

A triangle has V=3, E=3 and F=2 (inside and outside), so 3−3+2=2.

Exam takeawayCount the outside face and substitute into the formula.
07

The handshaking lemma and degree

In a finite undirected graph, the sum of all vertex degrees is 2|E| because every edge touches two ends. This means the number of odd-degree vertices must be even. The result provides a quick consistency check for a diagram and helps decide whether an Euler trail or circuit can exist.

Simple example

If degrees are 3, 2, 2 and 1, their sum is 8, so the graph has 4 edges.

Exam takeawayCount each loop according to the course convention and check the degree sum.
08

Euler trails and circuits

An Euler trail uses every edge exactly once; an Euler circuit also returns to its starting vertex. In a connected undirected graph, an Euler circuit requires every vertex to have even degree; an open Euler trail requires exactly two odd-degree vertices. These conditions concern edges, not whether every vertex is visited once.

Simple example

A connected graph with degrees 2, 2, 2 and 4 can have an Euler circuit.

Exam takeawayCheck connectivity and count odd-degree vertices before naming the route.
09

Hamilton paths and cycles

A Hamilton path visits every vertex exactly once; a Hamilton cycle returns to the start after visiting every vertex once. Unlike Euler problems, Hamilton problems do not require using every edge. There is no single simple degree test that decides every graph, so a careful route construction or proof of impossibility is usually needed.

Simple example

A route A→B→D→C visits four vertices once, even if some graph edges remain unused.

Exam takeawaySay explicitly whether the condition is about every vertex or every edge.
10

Planar graphs and faces

A planar graph can be drawn without edges crossing except at vertices. For a connected planar graph, Euler's formula is V−E+F=2, where F includes the outside face. The formula can help find a missing value, but only after confirming the graph is connected and planar. A drawing with crossings does not prove nonplanarity; it may be possible to redraw it.

Simple example

If V=6 and E=9 in a connected planar drawing, F=2−6+9=5.

Exam takeawayDefine the outside face and state the assumptions before applying the formula.
11

Adjacency matrices and graph representation

An adjacency matrix records which vertex pairs share an edge. For a simple undirected graph it is symmetric; diagonal entries are usually zero unless loops are allowed. The sum of a row gives the vertex degree in a simple graph. A matrix can make path algorithms and computer storage easier than drawing a large network.

Simple example

For edges A–B and B–C, rows A,B,C are [0,1,0], [1,0,1], [0,1,0].

Exam takeawayKeep vertex order fixed across row and column labels.
12

Connected components and bridges

A connected component is a maximal set of vertices joined by paths. A bridge is an edge whose removal increases the number of components. Bridges identify fragile links in transportation or communication networks. To test one, remove it on a sketch and check whether some vertices can no longer reach one another.

Simple example

In a chain A–B–C, each edge is a bridge; in a triangle, no single edge is a bridge.

Exam takeawayShow the graph before and after removing the candidate edge.
13

Euler trails and degree conditions

For a connected undirected graph, an Euler circuit exists when all vertices have even degree. An open Euler trail exists when exactly two vertices have odd degree; those odd-degree vertices are the start and end. Connectivity among non-isolated vertices matters. These criteria are sufficient as well as necessary for the standard case.

Simple example

Degrees 1,2,2,1 give two odd vertices, so an Euler trail can start at one and end at the other.

Exam takeawayCount degrees, check connectivity and identify the route endpoints.
14

Graph coloring and chromatic number

A proper vertex coloring assigns colors so adjacent vertices receive different colors. The chromatic number is the smallest number of colors required. Coloring can model exam timetables or register allocation, where conflicts prevent two tasks from sharing a time or resource. A shown coloring gives an upper bound; proving a minimum also requires a lower-bound argument.

Simple example

A triangle needs three colors because each pair of its three vertices is adjacent.

Exam takeawayGive a valid coloring and explain why fewer colors cannot work.
15

Graph vocabulary and representations

A graph consists of vertices and edges. A simple undirected graph has no loops or repeated edges; directed graphs use ordered edges, and weighted graphs attach values such as cost or distance. An adjacency list stores each vertex's neighbors; an adjacency matrix records whether each vertex pair is connected. Choose the representation that suits the task.

Simple example

For edges {AB, AC, BC}, the adjacency list of A is B,C and its matrix row is 0,1,1.

Exam takeawayState whether the graph is directed, weighted or simple before applying a theorem.
16

Degree and the handshaking lemma

The degree of a vertex is the number of incident edges; a loop contributes two in an undirected graph. The handshaking lemma says the sum of all vertex degrees equals 2|E| because each edge touches two ends. Therefore, an undirected graph must have an even number of odd-degree vertices.

Simple example

Degrees 3,2,3,2 sum to 10, so the graph has 5 edges and exactly two odd-degree vertices.

Exam takeawayAdd every degree and divide by two to check the edge count.
17

Walks, trails, paths and cycles

A walk may revisit vertices and edges; a trail does not repeat edges; a path does not repeat vertices; and a cycle returns to its starting vertex. Textbooks sometimes vary terminology, so state the definition used. Distinguish these carefully in questions about route existence, connectivity and graph traversal.

Simple example

A→B→C→B is a walk and may be a trail if edges differ, but it is not a path because B repeats.

Exam takeawayTrace the route and mark separately whether a vertex or an edge is repeated.
18

Euler trails and circuits

An Euler trail uses every edge exactly once; an Euler circuit also ends where it started. In a connected undirected graph, an Euler circuit exists when every vertex has even degree, while an open Euler trail exists when exactly two vertices have odd degree. The question concerns edges, not visiting every vertex just once.

Simple example

Degrees 3,2,3,2 give exactly two odd vertices, so a connected graph has an open Euler trail but no Euler circuit.

Exam takeawayCheck connectivity and count odd-degree vertices before giving the conclusion.
19

Hamilton paths and cycles

A Hamilton path visits each vertex exactly once; a Hamilton cycle also returns to the starting vertex. Unlike Euler questions, Hamilton questions focus on vertices rather than using every edge. There is no simple degree test that solves every graph, so construct a valid route or use a stated theorem when its conditions apply.

Simple example

For a square cycle A–B–C–D–A, every vertex is visited once before returning to A.

Exam takeawayList the route and verify every vertex appears exactly once.
20

Trees, spanning trees and traversal

A tree is connected and has no cycles. A tree with n vertices has n−1 edges; adding an edge creates a cycle, while removing an edge disconnects it. A spanning tree connects every vertex of a connected graph with the minimum number of edges. Breadth-first search explores level by level; depth-first search follows a branch before backtracking.

Simple example

A tree on 6 vertices has 5 edges. A BFS from A visits all distance-1 neighbors before distance-2 vertices.

Exam takeawayUse n−1 as a quick check and show the traversal queue or stack order.

How the unit fits together

Connect the definitions, methods and applications before you start memorizing.

Graph theory separates a network's structure from its physical appearance. A drawing may move vertices around, but the important information is which vertices are connected. Degrees reveal route properties: Euler circuits use every edge once, so each arrival must pair with a departure, producing even degree at every vertex in a connected graph. Hamiltonian cycles ask a different question: can each vertex be visited once? Trees provide a minimal connected structure without cycles; spanning trees keep all vertices while removing redundant edges. For planar graphs, faces count regions, including the outside. State the graph assumptions because directed, disconnected or non-planar graphs require different reasoning.

Quick recap: teach these links back

01

Graphs model relationships

A graph has vertices and edges. A path follows connected edges; a cycle returns to its start. The degree of a vertex is the number of edges touching it. Graphs can model roads, computer networks or relationships without needing real distances.

02

Trees connect without loops

A tree is connected and has no cycles. With n vertices it has n−1 edges: each new vertex needs one edge to remain connected, and an extra edge would create a cycle. A spanning tree uses every vertex of a connected graph with the minimum number of edges needed for connectivity.

03

Euler asks about edges; Hamilton asks about vertices

An Euler circuit uses every edge exactly once and returns to its start; in a connected undirected graph, each vertex must have even degree. A Hamiltonian cycle visits each vertex exactly once before returning and need not use every edge. For a connected planar graph, V−E+F=2, where F includes the outside region.

EXAMPLE 1

Check for an Euler circuit

TaskA connected simple graph has degrees 3, 2, 3 and 2. Does it have an Euler circuit?

  1. Confirm the graph is connected; the diagram shows every vertex is reachable.
  2. Count odd-degree vertices: A and C each have degree 3, so there are exactly two.
  3. An Euler circuit requires every vertex to have even degree, so this graph cannot have one.
  4. Because there are exactly two odd vertices and the graph is connected, an open Euler trail can start at one odd vertex and finish at the other.
Answer and reason

No Euler circuit exists. The graph does have an Euler trail from A to C (or C to A). The rule concerns using every edge exactly once.

EXAMPLE 2

Use Euler's planar formula

TaskA connected planar drawing has 6 vertices and 9 edges. Find its faces.

  1. Write V−E+F=2.
  2. Substitute V=6 and E=9: 6−9+F=2.
  3. Simplify: F−3=2, so F=5.
  4. Include the outside region in the face count.
Answer and reason

There are 5 faces, including the unbounded outside face.

QUESTION 1Distinguish Euler and Hamiltonian circuits.+

An Euler circuit uses every edge exactly once and returns to its start; vertices may be visited more than once. A Hamiltonian cycle visits each vertex exactly once before returning to its start; it does not require using every edge. The distinction is whether the condition concerns edges or vertices. For a connected undirected graph, an Euler circuit exists when every vertex has even degree.

QUESTION 2What is a spanning tree? Explain why it has n-1 edges.+

A spanning tree is a connected, cycle-free subgraph containing all vertices of a connected graph. A basic tree with one vertex has zero edges. Each time a new vertex is added while preserving connectivity and avoiding cycles, exactly one edge is added. Therefore a tree with n vertices has n-1 edges. A spanning tree is useful for connecting network sites with no redundant links.

WORK IT THROUGH

A connected tree has 6 vertices. How many edges?

  1. Use the tree rule E=n−1.
  2. Substitute n=6: E=6−1=5.
  3. Adding another edge between existing vertices creates a cycle, so the result is no longer a tree.

WATCH OUT FOR

Easy mix-ups

  • Euler conditions concern edges; Hamiltonian conditions concern vertices.
  • A spanning tree includes all vertices but only enough edges to connect them.
  • Count the outside region when using V−E+F=2.
